## 12. WHY IT WILL PERFORM
- **Pattern break on the greendipz grid.** Current greendipz feed is 100% reels + real-food photography. A premium editorial static carousel is a scroll-stopper *because* it looks nothing like standard greendipz output — pattern interruption drives dwell.
- **5-slide swipe forces linear reveal.** Each product gets a dedicated cover; the swipe motion is a save signal Instagram rewards.
- **Vivid Green spine = feed thumbnail recognition.** All 5 slides read as greendipz even before the label is legible — grid-level brand equity.
- **Magazine-series framing is ownable and extensible.** Issue 002, 003, 004 can extend this into a repeatable identity system, not a one-off.
- **Pack fidelity + editorial type = premium credibility.** Reader reads the pack accurately AND the presentation reads as high-craft — trust signal for the "no fake red / no artificial" claims.
- **Slide 5 is a direct-response cover.** Big centred SHOP NOW ON BIOMART.IN + full lineup + tagline = the tightest possible conversion close for a static.
- **Contrarian bet vs June repositioning ("100% reels").** New arrival reveals are one of the few post types where a premium static carousel outperforms a reel — collection reveals reward lingering, not scrolling. Worth testing to validate whether the reel-only rule should have an exception clause for release drops.
