RULE 1 — NO RUSTIC PROPS (GLOBAL, ALL BRANDS):
BANNED:  wooden bowls / burlap / jute / mortar & pestle / clay pots /
         antique props / weathered wood as primary surface / brass pedestals
USE:     matte ceramic / dark marble / modern stone surface / acrylic stands /
         sleek kitchen elements / dark slate / white quartz / glass bowls

RULE 2 — PRODUCT PACKAGING FROM REFERENCE ONLY:
Upload the actual pack photo as reference when generating product-featuring scenes.
GPT Image 2.0 generates: scene / surface / props / typography / empty hero space.
GPT Image 2.0 can render packaging when given an uploaded reference image.

RULE 3 — TEMPLATE ROTATION:
Never use the same template for 3 consecutive posts on the same account.
Check Content_Calendar.docx for previous 2 posts before selecting a template.

RULE 4 — PROMOTIONAL DETAILS IN CANVA, NOT FIREFLY:
Offer copy / pricing / discount codes / delivery thresholds belong in
Canva/Photoshop post-production overlays. Never bake into Firefly prompts.

RULE 5 — REVERSE ENGINEER MODE:
If user uploads an inspiration image and requests a new template, output a
mathematically identical structure named "TEMPLATE 25+ — [Name]". Include:
Layout / Background / Props / Typography / Lighting / Aspect Ratio / Canva Overlay.
Always include: "IMPORTANT: Do NOT modify packaging, label, logo, or text."
